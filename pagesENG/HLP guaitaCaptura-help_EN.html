Guaita Captura

Screenshot and clipboard manager in a single HTML file. Capture, archive, name, reuse and print. It installs nothing, connects to no server and keeps everything in your browser: your captures never leave your computer.

01 · Introduction

What guaitaCaptura is

guaitaCaptura brings five tasks together in one tool: capturing the screen, archiving captures in an orderly way, naming them with templates, reusing them (also as a manager for the system clipboard) and printing them or exporting them to PDF.

Preview version 0.2.0, not a Release Candidate. It is a test PWA ahead of the desktop (Electron) version. It may contain bugs and the internal archive format may change between versions. Export the archive (.zip) often and read the limitations before relying on it for important work.
Privacy: everything is processed locally in the browser. No accounts, no servers, no telemetry.

02 · Getting started

Opening and installing the app

The app works best when it is not opened by double-clicking the file (file://), because then the browser does not remember the clipboard permission and automatic history is disabled.

  1. Open it from an https:// address (for example GitHub Pages) or from http://localhost.
  2. In Chrome or Edge, use Install in the address bar to get it as a standalone offline app.
  3. The first time, the Limitations window opens. Press “Understood” when you have read it; you can reopen it from Help.
To serve it locally: inside the project folder run python -m http.server 8000 and open http://localhost:8000/pagesENG/guaitaCaptura.html.

By default, captures are stored in the browser's IndexedDB. The CAT and ENG versions share the same archive when opened from the same address.

03 · Interface

The screen
Menus

At the top: File, Capture, Edit, Clipboard, View, Help. Everything the program does is reachable from the cascading menus. Next to them, the quick buttons Capture, Crop and From clipboard.

Left panel

Search, archive views (All, Starred, Clipboard history, Texts, No collection), collections and tags.

Centre

The grid (or list) of thumbnails. You can drag files in to import them.

Right panel

At the top, the system clipboard; below, the detail of the selected item: name, collection, tags and notes.

The bottom bar shows the number of items, the space used, browser usage, whether storage is persistent and the date of the last export. The View menu lets you switch between grid and list, change the thumbnail size and hide the right panel.

04 · Capture

Getting captures into the archive

Capturing the screen

  1. Press Alt+S or the Capture button.
  2. The browser shows its dialog. The app proposes the type chosen in Capture › What the dialog proposes: entire screen (the default), window or tab.
  3. If you picked the entire screen, switch to the window you want to capture: the capture is taken 1.5 s after you leave the app (or after 10 s). That way guaitaCaptura does not appear in the image.
  4. Back in the app you find the preview: save it whole, crop it, annotate it, copy it to the clipboard or discard it.
The browser dialog can be neither avoided nor forced: the app only proposes a type, and the browser may ignore the proposal. There is no silent capture and no global shortcut. All of this will disappear with the Electron version.

Capture session: one dialog for many captures

Capture › Start a capture session (Alt+Shift+S) opens the dialog once and keeps the source open. From then on, each Alt+S captures without asking again. The active session is shown at the top right; stop it with the ✕ or from the browser.

05 · Crop

Adjustable crop and non-rectangular shapes

The crop tool opens when you capture (preview) and also on any image in the archive: the R key, Edit › Crop or right-click. When you crop an archived image, the original is kept and the crop is saved as a new capture.

ElementUse
ShapeRectangle, rounded corners (with radius), ellipse, polygon (click the vertices) and freehand lasso. Outside the shape, the result is transparent (PNG).
HandlesDrag the eight handles to adjust, or the inside to move the crop. In a closed polygon, drag the vertices.
RatioFree, 1:1, 4:3, 3:2, 16:9, A4 portrait or A4 landscape.
X, Y, W, HExact position and size in pixels.
LoupeMagnifies the pixels under the cursor and shows their coordinates.
KeyboardArrow keys move 1 px (Shift = 10 px), Ctrl+A selects everything, Enter saves and Esc discards. In a polygon, Backspace removes the last vertex.

Buttons: Save crop, Save whole, Save and annotate (opens the editor), Save and copy (also to the clipboard) and Discard. Right-click opens the context menu with the same actions.

06 · Archive

Organise, search and keep
  • Collections. Create them with the + in the left panel or from Edit › Move to collection. If a collection is open, new captures are saved straight into it. They can be renamed and deleted (items are kept without a collection).
  • Tags. Type them comma-separated in the detail. To assign tags to several items at once, select them and use “Add tags”.
  • Starred. S or the star in the detail.
  • Notes. Free text per item; it can also be printed under each image.
  • Search. Searches name, notes, tags, text and source.
  • Multiple selection. Ctrl+click, Shift+click and Ctrl+A. The arrow keys move the selection.

Exporting and importing the archive

File › Export the whole archive (.zip) creates a .zip with the images and a guaitaCaptura.json file holding names, collections, tags, notes and dates. To restore it, import the .zip: items that already exist are skipped. Export the selection downloads one image (or a .zip if there are several) in the format chosen in Settings (PNG, JPEG, WebP or original).

The archive lives in the browser, at the address where you used it. Clearing browsing data deletes it. Turn on persistent storage in Settings and make .zip backups regularly.

07 · Name

Name templates and batch rename

Each new capture gets a name from a template, configurable in File › Settings. The default is {source}_{date}_{time}_{n}.

TokenValue
{name}Current name (in batch rename) or the first words of a text
{date}Date YYYY-MM-DD
{time}Time hhmmss
{n}Sequential three-digit counter (001, 002…)
{col}Open collection
{source}capture, crop, clipboard, burst, pasted, imported…

The Catalan tokens ({origen} {data} {hora} {nom}) are also accepted. Characters not allowed in a file name are replaced with a hyphen.

Batch rename

Select several items and use Edit › Batch rename: choose the template and the starting number, and a preview is shown. It is applied from oldest to newest. To rename a single item, edit the “Name” field in the detail or press F2.

08 · Reuse

The clipboard and your items

The right panel shows the current content of the system clipboard (image or text) and lets you replace it with any item from the archive.

  1. Press Read to see what is on the clipboard (the browser asks for permission the first time).
  2. Press Save to archive if you want to keep it.
  3. Select an item in the archive and press Put selected item on it (or Ctrl+C). You can pick a scale first: original size, 50 %, 25 % or a maximum width of 1920, 1280 or 800 px.
  4. Switch to the other program (Word, an email, a drawing editor…) and paste with Ctrl+V.

The Clipboard menu also lets you put an item's name or notes on the clipboard as text.

Automatic history

When enabled, each time you return to the app the clipboard is read and, if there is new content, it is saved to the archive (the “Clipboard history” view). It only works if the permission is already granted and it does not read during a capture.

The browser does not allow watching the clipboard in the background: if you copy several things in a row in other programs, only the last one is saved. Images are always placed on the clipboard as PNG.

Other ways to reuse

  • Duplicate (Ctrl+D): makes a copy before editing.
  • Drag a thumbnail out of the app (to the desktop or file explorer, in Chrome/Edge) to save it as a file.
  • Download as PNG, JPEG, WebP or the original format.

09 · Editor

Annotate, draw and edit the image

Double-click an image, press E or use Edit › Annotate and edit. The tools are on the left; the properties and the Image, Selection and Object menus are at the top; right-click opens the context menu.

Editable objects

Everything you draw is an object. With the select tool (V) you can move it, resize it with the handles, rotate it with the round handle (Shift = 15° steps), duplicate it (Ctrl+D), delete it (Del), nudge it with the arrow keys and change its order (to front, forward, backward, to back). Objects are saved with the capture: when you open it again they can still be edited.

ToolsDetail
ShapesRectangle (R), rounded rectangle, ellipse (O), triangle, rhombus, star, revision cloud. Shift makes them regular.
LinesLine (L), arrow (F), double arrow, polyline and polygon (P): click the vertices and finish with a double-click or Enter.
FreehandPencil (D) and translucent marker (M).
TextText (T), callout with a movable tip, numbered step (N) and stamp (APPROVED, REVIEWED, REJECTED, DRAFT, CONFIDENTIAL, URGENT; double-click edits its text).
Highlight and hideHighlight (H), blur (B) and pixelate.

Properties: stroke and text colour, fill (click a swatch = stroke, Shift+click = fill), thickness, opacity, dashed line and text size. With an object selected, changes apply to it.

Colour

Image › Colour adjustments opens a panel with brightness, contrast, saturation, hue, greyscale, sepia and invert, with live preview. If you made a selection first, it only applies to that area. The Replace a colour tool swaps one colour for another: click the source colour in the image, choose the new colour and the tolerance, and press “Apply”.

Transparency

  • Magic wand (W): click a colour to make it transparent. Adjust the tolerance and choose whether only the contiguous area is affected.
  • Eraser (E): erases to transparent; thickness changes its size.
  • Selections (S): rectangular, elliptical, lasso or polygonal. Then, in the Selection menu: make it transparent (Del), make the outside transparent, crop the image to the selection, adjust its colour or copy it.
  • Overall opacity: makes the whole base image semi-transparent.

Image

Rotate 90°, flip, resize, add a margin or border (coloured or transparent) and merge the annotations into the image. There is zoom (fit, 50–400 %) and undo/redo (Ctrl+Z / Ctrl+Y).

Saving

Save (Ctrl+S) updates the capture; if you changed the base image (colour, transparency, size), it asks for confirmation. Save as copy creates a new capture and leaves the original untouched. To clipboard copies the result or the selected area.

Rotating, flipping, resizing and non-rectangular cropping merge the annotations into the image. The wand, the eraser and colour replacement act on the base image, not on the annotations. Blur protects nothing if you share the original capture: always share the edited version.

10 · Output

Print and export to PDF

File › Print (Ctrl+P) uses the selection or, if there is none, the current view.

OptionValues
Per page1, 2, 4 (2×2), 6 (2×3), 9 (3×3) or 16 (4×4, contact sheet)
OrientationA4 portrait or landscape
Caption under each imageName, name and notes, or none
HeaderFree text (by default, the name of the open collection)
  • Print… opens the browser dialog. Margins and scale may vary between browsers.
  • Export PDF generates a PDF directly, with no dependencies: JPEG images at 90 % quality (~200 dpi) and a footer with date and page number.
PDF text only supports Latin characters (Latin-1): other alphabets appear as “?”. Archived texts are printed as an image of their content.

12 · Limitations

Limitations of version 0.2.0
Preview version: not an RC. These limitations come from the browser; the Electron version will solve most of them.

Capture

  • The browser always shows its dialog; the app only proposes a type. A capture session avoids repeating it.
  • When capturing the entire screen you have to switch window; otherwise the app appears in the capture.
  • There is no global system shortcut.
  • It does not work on phones or tablets (they lack getDisplayMedia); there you can only paste or import.
  • The capture is a frame of the shared video: the browser's sharing notice may appear and, depending on the system, the cursor.
  • Cropping is done on the already captured image.

Clipboard

  • It cannot be watched in the background; it is only read when you return to the app.
  • Reading requires permission (Firefox and Safari have limited support).
  • Image and plain text only; rich formats and copied files are not kept.
  • When writing, images are always converted to PNG.
  • https or localhost is required. With file://, reading and writing may fail and automatic history is disabled.

Editor

  • Colour adjustments need a browser with canvas filters (recent Chrome, Edge, Firefox and Safari).
  • Rotating, flipping, resizing and non-rectangular cropping merge the annotations into the image.
  • The wand, the eraser and colour replacement act on the base image, not on the annotations.

Archive

  • The archive is in the browser's IndexedDB, tied to this browser and this address.
  • Space is limited by the browser quota.
  • There is no synchronisation between devices and no direct saving to a disk folder.

Printing and PDF

  • Margins and scale depend on the browser.
  • The PDF stores JPEG: transparent areas come out white. Latin characters only.

Not available yet

  • Sending to guaitaPDF Edit, guaita.MDeditor or other Guaita apps.
  • OCR of the captures.

13 · For developers

Towards Electron

The app detects window.guaitaBridge (exposed from the Electron preload) and, if present, uses it instead of the browser APIs. That way the same interface serves both versions:

window.guaitaBridge = {
  captureScreen(): Promise<Blob>,                       // capture without dialog (desktopCapturer)
  readClipboard(): Promise<{ image?: Blob, text?: string, types?: string[] }>,
  writeClipboard({ image?: Blob, text?: string }): Promise<void>,
  onClipboardChange(callback): void                     // continuous watching
};

Electron will add continuous clipboard watching with a complete history, global shortcuts, a system tray icon and capture without a dialog.

14 · FAQ

Frequently asked questions
The browser asks for clipboard permission again and again

This happens when the HTML is opened as a file (file://). Serve the app over https:// or localhost, or install it as a PWA. Since version 0.1.1 automatic history never asks for permission by itself.

Why can't I capture from my phone?

Mobile browsers do not offer screen capture to web pages. You can paste or import images.

I lost my captures

If browsing data was cleared, or the address or browser changed, the archive is not there. That is why you should export the .zip often and enable persistent storage.

Can I use the CAT and ENG versions at the same time?

Yes. They share the same archive when opened from the same address. The Help menu has a link to switch language.
